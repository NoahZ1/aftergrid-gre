# Aftergrid — GRE Adventure

A browser game combining voxel planetary mysteries with original GRE-style practice questions. No account, server, or API key required. Progress, question history, and response timing are saved on each player’s browser.

## Play locally

Run `python3 -m http.server 4173`, then open http://localhost:4173.

## Checks

Run `node --test tests/adventure.test.cjs`.

## Hosting

GitHub Actions publishes the main branch to GitHub Pages. Set Pages source to GitHub Actions in repository settings.

Questions are original practice material, not official ETS questions. Sprint goals are training targets, not predicted GRE scores.
